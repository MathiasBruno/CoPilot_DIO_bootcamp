# 🌍 EcoTripCalc

**Eco Calculator App** - A Spring Boot application that calculates the carbon footprint of trips and estimates the cost of carbon compensation.

## 📋 Overview

EcoTripCalc is an environmental calculator designed to help users understand the carbon emissions generated by their travels. The application calculates CO₂ emissions based on the mode of transportation and distance traveled, then estimates the cost to compensate for those emissions through carbon credits.

## ✨ Features

- **Carbon Emission Calculation**: Calculate CO₂ emissions based on transportation mode and distance
- **Carbon Credit Estimation**: Determine how many carbon credits are needed to offset emissions
- **Cost Estimation**: Calculate the financial cost of carbon compensation (in Brazilian Real - BRL)
- **Multiple Transportation Options**:
  - 🚴 Bicycle (0 kg CO₂/km)
  - 🚌 Bus (0.08 kg CO₂/km)
  - 🏍️ Motorcycle (0.12 kg CO₂/km)
  - 🚗 Car (0.19 kg CO₂/km)
- **Responsive Web Interface**: User-friendly UI built with HTML/CSS
- **RESTful API**: Easy integration with other applications

## 🛠️ Tech Stack

- **Backend**: Spring Boot 4.0.2
- **Language**: Java 17
- **Template Engine**: Thymeleaf

- **Frontend**: HTML5, CSS3, JavaScript

## 🚀 Getting Started

### 1. Clone or Navigate to the Project

```bash
cd EcoTripCalc
```

### 2. Build the Project

Using Maven wrapper (Windows):
```bash
mvnw.cmd clean package
```

Or if you have Maven installed globally:
```bash
mvn clean package
```

### 3. Run the Application

Using Maven wrapper:
```bash
mvnw.cmd spring-boot:run
```

Or directly with Java:
```bash
java -jar target/ecosimul-app-0.0.1-SNAPSHOT.jar
```

### 4. Access the Application

Open your browser and navigate to:
```
http://localhost:8080
```

## 📡 API Endpoints

### Calculate Carbon Impact

**Endpoint**: `POST /api/calcular`

**Request Body**:
```json
{
  "transporte": "carro",
  "distancia": 100
}
```

**Response**:
```json
{
  "co2EmitidoKg": 19.0,
  "creditosCarbono": 0.019,
  "custoEstimadoReais": 2.85
}
```

### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `transporte` | String | Mode of transportation: `bicicleta`, `onibus`, `moto`, `carro` |
| `distancia` | Double | Distance in kilometers |

### Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `co2EmitidoKg` | Double | Total CO₂ emitted in kilograms |
| `creditosCarbono` | Double | Number of carbon credits needed (1 credit = 1000 kg CO₂) |
| `custoEstimadoReais` | Double | Estimated cost in Brazilian Real (BRL) |

## 📊 Carbon Emission Factors

The application uses the following emission factors (CO₂ per kilometer):

| Transport Mode | Emission Factor (kg CO₂/km) |
|----------------|-----|
| Bicycle | 0.00 |
| Bus | 0.08 |
| Motorcycle | 0.12 |
| Car | 0.19 |

### Carbon Credit Pricing

- **Fixed Rate**: R$ 150.00 per carbon credit (1000 kg CO₂)

## ⚙️ Configuration

Edit `src/main/resources/application.properties` to customize the application:

```properties
# Server Port
server.port=8080

# Spring Thymeleaf Configuration
spring.thymeleaf.prefix=classpath:/templates/
spring.thymeleaf.suffix=.html
```

## 🔄 API CORS Configuration

The API is configured with CORS enabled to allow requests from any origin:

```java
@CrossOrigin(origins = "*")
```

This allows the HTML frontend to communicate with the REST API without restrictions.

## 📚 Example Usage

### Using cURL

```bash
curl -X POST http://localhost:8080/api/calcular \
  -H "Content-Type: application/json" \
  -d '{"transporte":"carro","distancia":100}'
```

### Using JavaScript (Fetch API)

```javascript
const dados = {
  transporte: 'carro',
  distancia: 100
};

fetch('http://localhost:8080/api/calcular', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify(dados)
})
.then(response => response.json())
.then(data => console.log(data))
.catch(error => console.error('Error:', error));
```

## 🐛 Troubleshooting

### Port Already in Use
If port 8080 is already in use, change it in `application.properties`:
```properties
server.port=8081
```

### CORS Issues
Make sure the CORS annotation is present in `CarbonSimulatorController.java`:
```java
@CrossOrigin(origins = "*")
```

### Build Failures
Ensure Java 17+ is installed:
```bash
java -version
```
